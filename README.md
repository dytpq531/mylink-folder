# 이요셉 MyLink Station

GitHub Pages에 그대로 게시할 수 있는 단일 HTML 웹페이지입니다. 별도 설치나 빌드 과정이 필요 없습니다.

## 포함 파일
- `index.html` : 완성된 웹페이지 (HTML + CSS + JavaScript 포함)
- `.nojekyll` : GitHub Pages 정적 배포 보조 파일
- `README.md` : 사용 및 제출 안내

## 사이트 구성
- 메인 인트로 / 프로필
- 네 가지 바로가기 링크
- 자기소개 / 관심 분야 필터 / 진로 로드맵
- 외부 참고 사이트 링크
- 버튼 클릭 시 자기소개 문구 복사 기능
- 모바일 반응형 및 키보드 접근성

## GitHub 업로드 방법 (GitHub 웹사이트 기준)
1. https://github.com/new 에서 새 저장소를 만듭니다.
2. Repository name: `mylink-folder` (원한다면 다른 이름도 가능)
3. Visibility를 **Public**으로 선택하고 저장소를 생성합니다.
4. 저장소 화면에서 `Add file` → `Upload files`로 이동합니다.
5. 이 폴더에 들어있는 `index.html`과 `.nojekyll`을 업로드합니다. (`README.md`는 선택)
6. `Commit changes`를 눌러 저장합니다.
7. 저장소 상단 `Settings` → 왼쪽 `Pages`로 갑니다.
8. `Build and deployment`에서 `Source`를 `Deploy from a branch`로 지정합니다.
9. `Branch: main`, `Folder: /(root)` 선택 후 `Save`를 누릅니다.
10. `https://본인GitHub아이디.github.io/mylink-folder/` 주소로 접속 가능한지 확인합니다.

## 과제 제출란에 적을 내용
GitHub 저장소 URL: `https://github.com/본인GitHub아이디/mylink-folder`
MyLink 공개 URL: `https://본인GitHub아이디.github.io/mylink-folder/`

**주의:** 위 주소는 예시입니다. 본인 GitHub 아이디로 바꾸고 실제로 접속해 확인해야 합니다.

## 게시 전 확인할 사항
- 이름과 전공은 요청에 따라 이요셉 / 설비소방학과로 넣었습니다.
- 사이트에 학번과 개인 연락처는 공개하지 않았습니다. 학번이 필요한 제출란에만 기입하세요.
- 외부 링크는 개인 계정이 아닌 공식 Q-net 홈페이지와 GitHub 홈페이지입니다. 실제 개인 계정 주소는 제공받지 않아 만들지 않았습니다.
- 사이트를 나중에 수정하려면 `index.html`을 텍스트 편집기로 열어 문구를 변경한 뒤 GitHub 저장소의 파일을 갱신하면 됩니다.
